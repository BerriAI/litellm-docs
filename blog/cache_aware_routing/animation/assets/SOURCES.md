# Animation icon sources

All icons are text-free symbols. No wordmarks or labels were added.

| File | Source |
| --- | --- |
| `claude-code.svg` | Existing LiteLLM docs asset, `static/img/cloud-agent-workshop/claude-code.svg` (same orange Claude symbol as the supplied reference) |
| `codex.svg` | Existing LiteLLM docs asset, `static/img/cloud-agent-workshop/codex.svg` (same Codex terminal symbol as the supplied reference) |
| `kubernetes.svg` | Existing LiteLLM docs asset, `static/img/cloud_icons/kubernetes.svg` |
| `litellm.svg` | Existing LiteLLM docs asset, `static/img/brand/litellm-monogram-blue.svg` |
| `vllm.svg` | Official [vLLM compact logo](https://github.com/vllm-project/media-kit/blob/main/vLLM-Logo.svg), fetched from vllm-project/media-kit main, Git blob `6b9e5d1df89be1b279583dc3b7565de483cb3662` |

This folder retains the Apache 2.0 license distributed with the existing Kubernetes docs icons. The vLLM media kit explicitly distributes these assets for use, asks users to preserve proportions and clear space, and lists its flat colors as yellow `#fdb515` and blue `#30a2ff`. Its README does not specify a separate license for the logo artwork. Existing harness and LiteLLM brand assets retain their source branding; this file makes no new licensing claim about them.

`codex.svg` has a three-stop gradient in the original artwork. The renderer replaces it with solid blue `#6C7EFF`, preserving its path geometry. All rendered colors are flat.
