# Animation asset source

`litellm.svg` is a byte-for-byte copy of this repository's `static/img/brand/litellm-monogram-blue.svg`, also used in the cache-aware routing animation. It uses the existing LiteLLM brand blue `#0117be` and a `0 0 372.14 371.53` SVG viewBox. The cover preserves its geometry and colors. White beneath the monogram's own silhouette keeps its negative-space train visible on dark backgrounds. Ownership and existing repository terms remain unchanged.
