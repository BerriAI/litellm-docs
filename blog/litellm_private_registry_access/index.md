The **LiteLLM Private Registry is now available**.

Public security patches can show attackers how a vulnerability works. For the most severe vulnerabilities, LiteLLM shares fixes privately first. This gives teams time to scan and deploy the patched version before the fix and security advisory become public. **LiteLLM continues to release all security fixes publicly.**

{/* truncate */}

The [October announcement](/blog/litellm-private-registry) introduced plans for the Private Registry.

## Request access

Customers with an existing confidentiality agreement with LiteLLM can contact [support](mailto:support@berri.ai) for registry access. LiteLLM is developing an access policy for open-source users. Share feedback in the [GitHub discussion](https://github.com/BerriAI/litellm/discussions/48643).
