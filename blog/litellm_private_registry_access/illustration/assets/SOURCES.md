# Illustration asset sources

The assets in this folder are original SVGs. Their icon geometry and colors are unchanged.

## AWS service icons

`ecr.svg` and `cognito.svg` come directly from the [official AWS Architecture Icons page](https://aws.amazon.com/architecture/icons/), downloaded on November 11, 2026. The page links to the [July 31, 2026 icon package](https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip).

The original archive paths are `Architecture-Service-Icons_07312026/Arch_Containers/64/Arch_Amazon-Elastic-Container-Registry_64.svg` and `Architecture-Service-Icons_07312026/Arch_Security-Identity/64/Arch_Amazon-Cognito_64.svg`. Both use an 80 by 80 SVG viewBox.

AWS owns these service marks. AWS's icon page permits customers and partners to use the toolkit assets in architecture diagrams and materials such as whitepapers, presentations, data sheets and posters. This provenance records that published usage permission; it does not relicense the AWS marks under this repository's license.

The illustration embeds the original AWS icon groups without changing their proportions, white glyphs, or category colors.

## LiteLLM monogram

`litellm.svg` is a byte-for-byte copy of this repository's `static/img/brand/litellm-monogram-blue.svg`, also used in the cache-aware routing animation at `blog/cache_aware_routing/animation/assets/litellm.svg`. It uses the existing LiteLLM brand blue `#0117be` and a `0 0 372.14 371.53` SVG viewBox. Dark mode uses the white fill from `static/img/brand/litellm-monogram-white.svg` with the same geometry. Ownership and existing repository terms remain unchanged.
