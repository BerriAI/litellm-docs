# AI Providers

LiteLLM calls every provider below through one OpenAI-format API. Set the model as `<prefix>/<model-name>`, for example `anthropic/claude-sonnet-5`, and the same request works from the Python SDK and the Gateway. Open a provider for its keys, setup, and supported parameters. Prices and context windows for each model are on [Models & Pricing](https://models.litellm.ai).
