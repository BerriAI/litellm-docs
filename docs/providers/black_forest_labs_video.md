# Black Forest Labs - Video Generation

LiteLLM supports Black Forest Labs' FLUX 3 video model for text-to-video, image-to-video, and video continuation, with synchronized audio generated in the same call.

| Property | Details |
|----------|---------|
| Description | FLUX 3 generates video with synchronized audio, from a prompt, from keyframe images, or continuing an existing clip |
| Provider Route | `black_forest_labs/flux-3-video` |
| Provider Doc | [Black Forest Labs FLUX 3 Video ↗](https://docs.bfl.ai/flux_3/flux3_video) |
| Supported Operations | `/v1/videos` |

## Quick Start

```python showLineNumbers title="Basic Video Generation"
from litellm import video_generation
import os

os.environ["BFL_API_KEY"] = "your-api-key"

response = video_generation(
    model="black_forest_labs/flux-3-video",
    prompt="A white kitten chases a butterfly across a sunlit garden. Gentle camera tracking, birdsong.",
    seconds="8",
    size="1920x1080",
)

print(f"Video ID: {response.id}")
print(f"Status: {response.status}")
```

## Authentication

```python showLineNumbers title="Set API Key"
import os

os.environ["BFL_API_KEY"] = "your-api-key"
```

`BLACK_FOREST_LABS_API_KEY` is also accepted.

## Supported Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `model` | string | Yes | `black_forest_labs/flux-3-video` |
| `prompt` | string | Yes | Text description of the video. Not used in `draft_enhance` mode |
| `seconds` | string/int | No | Clip length in whole seconds, 5 to 20. Values outside the range are clamped. Omit to let FLUX 3 fit the duration to the content |
| `size` | string | No | Mapped onto a resolution tier by its shorter side: at most 720 becomes `hd`, larger becomes `fhd`. Pass `hd` or `fhd` directly to skip the mapping |
| `input_reference` | string | No | Image URL or data URI used as the opening frame, which selects image-to-video |

FLUX 3 parameters not covered by the OpenAI shape are passed through, so `aspect_ratio`, `generate_audio`, `safety_tolerance`, `draft`, `keyframes`, `start_video`, and `draft_cache` all work as documented in the [FLUX 3 API reference](https://docs.bfl.ai/api-reference/utility/generate-a-video-with-flux-3).

Audio is generated by default, so `generate_audio` only has to be set to turn it off.

## Generation modes

FLUX 3 is a single endpoint with a `mode` discriminator. LiteLLM infers the mode from the inputs, so you rarely set it yourself.

| Mode | Selected by | Description |
|------|-------------|-------------|
| `t2v` | a prompt alone | Text-to-video |
| `i2v` | `input_reference` or `keyframes` | Animate one or more images |
| `v2v` | `start_video` | Continue from the final frames of an existing MP4 |
| `draft_enhance` | `draft_cache` | Re-render a draft at full quality |

## Complete Workflow

```python showLineNumbers title="Complete Video Generation Workflow"
from litellm import video_generation, video_status, video_content
import os
import time

os.environ["BFL_API_KEY"] = "your-api-key"

response = video_generation(
    model="black_forest_labs/flux-3-video",
    prompt="A white kitten chases a butterfly across a sunlit garden. Gentle camera tracking, birdsong.",
    seconds="8",
    size="1920x1080",
)

video_id = response.id
print(f"Video generation started: {video_id}")

while True:
    status_response = video_status(video_id=video_id)
    print(f"Status: {status_response.status}")

    if status_response.status == "completed":
        break
    elif status_response.status == "failed":
        print(f"Video generation failed: {status_response.error}")
        break

    time.sleep(10)

video_bytes = video_content(video_id=video_id)

with open("generated_video.mp4", "wb") as f:
    f.write(video_bytes)
```

## Image to Video

```python showLineNumbers title="Animate a Starting Image"
from litellm import video_generation
import os

os.environ["BFL_API_KEY"] = "your-api-key"

response = video_generation(
    model="black_forest_labs/flux-3-video",
    prompt="The cat trots across the sunlit room and settles by the window.",
    input_reference="https://example.com/first-frame.png",
    seconds="6",
)
```

Pass `keyframes` directly for the shapes a single image cannot express: more than two images, or images pinned to a specific second. One image opens the clip, two open and close it, and with more the extras are spaced evenly in between.

```python showLineNumbers title="Timed Keyframes"
response = video_generation(
    model="black_forest_labs/flux-3-video",
    prompt="The camera drifts between the two rooms.",
    keyframes=[[0, "https://example.com/first.png"], [6, "https://example.com/last.png"]],
    seconds="6",
)
```

## Draft Mode

Drafts render at `hd` and cost about a third of a full render, so you can explore variants and only pay full price for the shot you keep. A draft returns an encrypted bundle; sending that bundle back as `draft_cache` re-renders the same generation at full quality.

```python showLineNumbers title="Draft, then Enhance"
from litellm import video_generation
import os

os.environ["BFL_API_KEY"] = "your-api-key"

draft = video_generation(
    model="black_forest_labs/flux-3-video",
    prompt="A white kitten chases a butterfly across a sunlit garden.",
    seconds="6",
    draft=True,
)
```

## Async Usage

```python showLineNumbers title="Async Video Generation"
from litellm import avideo_generation, avideo_status, avideo_content
import os
import asyncio

os.environ["BFL_API_KEY"] = "your-api-key"

async def generate_video():
    response = await avideo_generation(
        model="black_forest_labs/flux-3-video",
        prompt="A serene lake with mountains in the background.",
        seconds="5",
    )

    while True:
        status_response = await avideo_status(video_id=response.id)
        if status_response.status in ("completed", "failed"):
            break
        await asyncio.sleep(10)

    video_bytes = await avideo_content(video_id=response.id)
    with open("generated_video.mp4", "wb") as f:
        f.write(video_bytes)

asyncio.run(generate_video())
```

## LiteLLM Proxy Usage

Add the model to your config:

```yaml showLineNumbers title="config.yaml"
model_list:
  - model_name: flux-3-video
    litellm_params:
      model: black_forest_labs/flux-3-video
      api_key: os.environ/BFL_API_KEY
```

Then call it through the proxy:

```bash showLineNumbers title="Create a video"
curl http://localhost:4000/v1/videos \
  -H "Authorization: Bearer sk-1234" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "flux-3-video",
    "prompt": "A white kitten chases a butterfly across a sunlit garden.",
    "seconds": "5"
  }'
```

```bash showLineNumbers title="Poll status and download"
curl http://localhost:4000/v1/videos/<video_id> \
  -H "Authorization: Bearer sk-1234"

curl http://localhost:4000/v1/videos/<video_id>/content \
  -H "Authorization: Bearer sk-1234" \
  --output generated_video.mp4
```

## Cost Tracking

FLUX 3 video is priced per second of output, and the rate depends on the mode and resolution. Text-to-video and image-to-video are $0.17/s at `hd` and $0.29/s at `fhd`; video continuation is $0.43/s at `hd` and $0.54/s at `fhd`; drafts are $0.06/s and $0.12/s respectively. See [Black Forest Labs pricing](https://docs.bfl.ai/quick_start/pricing).

The credits Black Forest Labs charged for a job are reported on the status response:

```python showLineNumbers title="Reported credits"
status_response = video_status(video_id=video_id)
print(status_response.usage)  # {'credits': 30.0}
```

## Unsupported Operations

The FLUX 3 video API has no remix, list, or delete route, so `video_remix`, listing, and deletion raise `NotImplementedError` for this provider.
