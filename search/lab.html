How this experiment works

The existing search engine selects up to 100 candidate pages. Jev estimates whether each page is the best first destination for a LiteLLM visitor’s likely task. It sees titles, descriptions, keywords, breadcrumbs, headings, tab labels, links, table headers, image descriptions, code example labels, and callout titles, plus the indexed text of shorter pages. Longer pages include the introduction and several relevant passages. Context limits preserve structural signals before body passages. Scores are independent estimates of first-page suitability, not measured percentages of users, and do not sum to 100%.

Candidates load after a 250 ms typing pause. Jev starts after 450 ms; results appear in one final order, and outdated requests are cancelled. Successful rankings are cached for 15 minutes. Displayed timing covers retrieval and the server call, excluding the typing pause. This local experiment uses a snapshot of the live public docs corpus.
